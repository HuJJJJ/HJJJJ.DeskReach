# ST7789 四线串行时序学习例程

目标：把时序图里的电平变化与 STM32F1 的代码逐句对应起来。
使用 STM32F103 / STM32Cube HAL；这是独立的写入时序示例，不是完整屏幕初始化或显示工程。

## 接线与工程准备

| STM32 示例引脚 | 屏幕标记 | 作用 |
|---|---|---|
| PA4 | CS / CSX | 片选，低有效 |
| PA5 | SCL / SCK / CLK | 串行时钟 |
| PA7 | SDA / DIN / MOSI | STM32 发给屏幕的数据 |
| PB1 | DC / D/C / A0 | 0=命令，1=参数或像素数据 |
| PB0 | RES / RST | 复位，低有效 |
| GND | GND | 共地 |

以上引脚是本例的选择，不是对实际板子接线的确认。模块需要支持带独立 DC 的四线串行模式。
供电和 BL/LED 背光按模块说明连接；采用与模块兼容的 3.3 V 逻辑，不要把背光脚当成 SCL。
DOUT/SDO 只读回时使用，本例不用；有的模块没有引出该脚。

1. 准备一个能正常运行 HAL_Delay 的 STM32F103 HAL 工程。
2. 添加 st7789_spi_lesson.c 和 .h，并设置头文件路径。
3. 保留工程原有的 HAL_Init、SystemClock_Config 和系统时基。
4. 本例使用普通推挽 GPIO，不需要启用 SPI1；不要让其他外设占用这些引脚。
5. 把下面的调用放在 main 的初始化部分、原有板级初始化之后、while(1) 之前。

```c
#include "st7789_spi_lesson.h"

/* main 中已有：HAL_Init(); SystemClock_Config(); 以及需要的板级初始化 */
LCD_BusInit();
LCD_Reset();

LCD_WriteCommand(0x11);  /* 退出睡眠 */
HAL_Delay(120);

LCD_WriteCommand(0x3A);  /* 命令：设置像素数据格式 */
LCD_WriteData(0x55);     /* 参数：16 位 / 像素，RGB565 */
```

这段调用适合观察通信波形，不保证屏幕显示图像。点亮屏幕还需要符合模块要求的初始化、显示开启、地址窗口和像素数据；方向、偏移、反色和背光也取决于实际模块。

## 读图顺序

横轴是时间，从左往右。每行是一个信号，上面为高电平，下面为低电平；不同信号在同一竖线上的位置表示同一时刻。高低之间的斜线表示电平转换不是瞬间完成。

SDA 和 DC 的交叉双线是通用时序画法，表示允许为高或低、以及新旧值交替的边界，不是两根线，也不要求每个时钟都翻转 SDA。

写一位时：CS 保持低 → SCL 保持低 → 放好 SDA → 稍等 → SCL 上升 → SDA 继续保持 → SCL 下降。
写一个字节时：重复八次，顺序 D7、D6、D5、D4、D3、D2、D1、D0。DC 整个字节保持不变。

四线模式下 DC 在第八个上升沿被锁存；本例从字节开始前就设置并一直保持，方便学习并留足余量。
CS 可以跨多个完整字节一直保持低，也可以在完整字节之间释放。本例每个字节释放一次；不要在半个字节中途释放。

## 图中字母与代码

| 参数 | 通俗意思 | 本例如何留出时间 |
|---|---|---|
| TCSS | 选中屏幕后，第一次采样前等多久 | LCD_Begin 的等待及首位等待 |
| TCSH | 最后一个写入采样沿之后，片选还保持多久 | 高电平等待及 LCD_End 的等待 |
| TCHW | 两次传输之间 CS 高多久 | CS_H 后等待 |
| TSCYCW | 一整个写时钟周期 | 相邻上升沿之间的时间 |
| TSHW / TSLW | 写时钟高 / 低各持续多久 | 两次 LCD_Wait 及 GPIO 操作 |
| TSDS | 上升沿之前，SDA 至少提前稳定多久 | SDA 设置之后的 LCD_Wait |
| TSDH | 上升沿之后，SDA 至少继续稳定多久 | SCL_H 之后的 LCD_Wait |
| TDCS / TDCH | DC 在其采样沿前后稳定多久 | 整个字节保持 DC 不变 |
| TSCYCR / TSHR / TSLR | 读操作的周期、高脉宽、低脉宽 | 本例不读回 |
| TSCC | 读操作的片选保持要求 | 本例不读回 |
| TACC / TOH | 读回数据出现、保持/退出有效输出的时序 | 本例不读回 |

TACC 是读时钟触发后，屏幕输出有效数据的等待时间。TOH 按图看是输出保持/退出有效输出的时间窗；所参考 V1.2 表中名称为 Output disable time。读操作还需按具体命令处理 dummy clock，不是简单把发送函数反过来。

VIH、VIL 是判定高低电平的门槛，不是程序里的延时量。看延时必须同时看手册表格的 MIN / MAX 和单位；图形距离通常不按真实时间比例画。

## 学习时故意慢

LCD_Wait 使用 HAL_Delay(1)，单位为毫秒，实际时长受 HAL 时基影响。
1 ms = 1,000 us = 1,000,000 ns。这远大于写入建立/保持时间的纳秒量级，方便观察，但刷屏会非常慢。
加长平台时间并不等于电气波形一定合格；接线电容、驱动能力和电平转换斜率仍需要在实体硬件上检查。
不要在中断里调用，也不要禁用提供 HAL tick 的中断后调用。

理解后可将传输层换为硬件 SPI：本例的低电平空闲、上升沿采样对应 CPOL=0、CPHA=0（Mode 0），8 位，MSB first，CS 和 DC 继续由 GPIO 控制。更换硬件 SPI 时需将时钟/数据脚配置为正确复用功能，并确认发送真正结束后才释放 CS。

## 两个练习

1. 0x3A = 00111010：按八次上升沿依次读出 0、0、1、1、1、0、1、0。
2. 0x55 = 01010101：SDA 交替变化。随后试 0x00；虽然 SDA 始终低，仍然必须有八个时钟脉冲。

不要用随机字节作屏幕命令；独立练习任意波形可以只观察 GPIO 或将屏幕断开后测量。
